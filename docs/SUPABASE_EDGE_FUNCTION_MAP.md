# Supabase Edge Function update: карта и косметика

## Что делает обновлённая функция
- Сохраняет проверку Telegram Web App initData на сервере.
- Добавляет действие `map_sightings`: возвращает до 100 опубликованных находок из `cat_sightings`.
- Сохраняет выбор рамки аватара, аксессуара и стиля карточек в `catgo_players` с allowlist-проверкой.
- Возвращает косметические поля в `profile` и `public_profile`.

## Важно: это ещё не публикация находок
Действие чтения карты заработает после применения миграции `202610280001_catgo_map_android_ai.sql`.
Сохранение косметики требует также `202610280002_catgo_profile_cosmetics.sql`.
Пока нет действия `map_create_sighting`, формы публикации фото, загрузки в Storage и ИИ-проверки. Не добавляйте публичную запись в таблицу напрямую из клиента.

## Как обновить функцию
1. Скачайте обновлённый `index.ts`, подготовленный для этой версии.
2. В Supabase Dashboard откройте Edge Functions → `catgo-player` → Code.
3. Замените код функцией из файла, сохраните и задеплойте.
4. Проверьте Logs после открытия Cat Go и убедитесь, что нет ошибки о колонках `avatar_frame_key`, `avatar_accessory_key`, `cat_card_style_key`.
5. В Supabase SQL Editor примените миграции в порядке: `202610280001`, затем `202610280002`.

## Администратор и бесконечный уровень
В интерфейсе режим владельца пока включается для username `@elchervei` только для просмотра косметики. Username не является безопасным подтверждением администратора: для настоящих серверных привилегий нужно задать числовой Telegram ID владельца в Supabase Secret и сравнивать его только с ID из проверенного `initData`. Не используйте клиентское поле `isAdmin` как доказательство прав.
