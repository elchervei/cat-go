# Cat Go: публикация находок на общей карте

## Что добавлено
- Форма публикации находки в разделе «Карта»: фото из галереи, имя кота, описание и точка на карте.
- Фото сжимается в браузере и отправляется в `catgo-player` Edge Function.
- Edge Function должна проверять Telegram `initData`, размер JPEG, координаты и лимит 5 публикаций в час, загружать фото в Storage и создавать запись в `cat_sightings`.
- Координаты округляются примерно до 100 м, чтобы не показывать точный адрес.
- Важно: AI-проверка, что на фото именно кот, пока не подключена. До подключения AI публикуйте только реальные фото котов.

## Порядок включения
1. В Supabase → SQL Editor запустите миграции в порядке:
   - `202610280001_catgo_map_android_ai.sql`
   - `202610280002_catgo_profile_cosmetics.sql`
   - `202610280003_cat_sightings_storage.sql`
2. Замените код функции `catgo-player` на файл `catgo-player-index-publish.ts` из этого релиза и нажмите Deploy.
3. Убедитесь, что у Edge Function заданы секреты `TELEGRAM_BOT_TOKEN`, `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`. Service-role key нельзя помещать во frontend.
4. После сборки Vercel откройте Cat Go через Telegram, перейдите в «Карта», выберите точку и загрузите JPEG-фото.

## Ограничения текущей версии
- Валидация подтверждает формат и размер файла, но не распознаёт содержимое фото.
- Публичная ссылка на загруженный файл доступна всем, как и сама находка.
- Не указывайте точное местоположение частного дома; сервер округляет координаты, но это не заменяет осмотр точки перед публикацией.
