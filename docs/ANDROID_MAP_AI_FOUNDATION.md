# Cat Go: Android, карта и ИИ — план интеграции

## 1. Что уже добавлено в интерфейс
- Настоящая интерактивная карта OpenStreetMap (Leaflet), приближение/перемещение и выбор точки нажатием.
- Геолокация запрашивается только после нажатия «Моё место».
- Экран пытается читать общие метки через Edge Function action `map_sightings`. Пока функция не поддерживает это действие, экран честно показывает статус «База меток подключается».
- Для Telegram-профиля с username `@elchervei` включён **режим просмотра косметики**: показывает уровень ∞ и открывает все фоны/рамки/аксессуары/стили. Это UI-предпросмотр, не серверная привилегия и не меняет XP. Для настоящего серверного админ-доступа нужен проверенный Telegram numeric ID и проверка в Edge Function.
- SQL-миграция создаёт таблицы для публичных находок, AI-анализов и привязки способов входа.

## 2. Следующий серверный шаг карты
Обновить Supabase Edge Function `catgo-player` (её исходник не лежит в этом GitHub-репозитории) и добавить actions:
- `map_sightings`: вернуть опубликованные находки, ограничить выдачу до 100, по возможности фильтровать bbox; отдавать только публичные поля.
- `map_create_sighting`: проверить Telegram `initData` подпись на сервере (или Supabase JWT), ограничить частоту публикаций, проверить, что это фото кота после ИИ-проверки, загрузить изображение в приватный/публичный bucket Supabase Storage, сохранить URL/путь и координаты.
- `map_hide_sighting`: владелец или модератор может скрыть метку.
- Никогда не принимать `created_by_telegram_id` от клиента как доказательство личности. Получать ID только из проверенного Telegram initData.
- Не публиковать точный адрес жилья. По умолчанию округлять координаты или показывать приблизительную область.

### Storage
Создать bucket `cat-sightings`. Для MVP предпочтительнее загрузка через Edge Function или signed upload URL с коротким сроком жизни. Не хранить большие base64-строки в таблицах.

## 3. Android и вход через Google/Apple/email
Рекомендуемый путь — React/Vite UI оставить общим, затем упаковать Android через Capacitor. Это позволит сохранить веб-версию Telegram Mini App и добавить Android APK/AAB без переписывания экранов.
1. В Supabase Dashboard → Authentication → Providers включить Google; настроить OAuth Client в Google Cloud и redirect URL из Supabase.
2. При необходимости включить Apple и Email OTP. Не хранить пароли самостоятельно.
3. В приложении Android использовать Supabase Auth OAuth через системный браузер и deep link обратно в приложение; для Capacitor добавить платформу Android и настроить callback/deep-link.
4. Добавить экран входа только для standalone Android. В Telegram Mini App продолжать проверять Telegram `initData`.
5. При привязке Telegram к аккаунту сначала проверить действующий Supabase session, затем серверно проверить Telegram initData и атомарно связать `auth_user_id` с `telegram_id`. Запретить связывать ID, который уже привязан к другому аккаунту.
6. Не использовать username Telegram как ключ аккаунта. Основной ключ — numeric Telegram ID, подтверждённый подписью, или Supabase Auth UUID.
7. Настроить Android application ID, signing key, app links, privacy policy, account deletion, Data Safety и тестовый internal track в Google Play Console.

Текущий проект — веб-приложение. Эта миграция подготавливает схему, но ещё не создаёт Android APK/AAB и не включает Google OAuth: для этого нужны настройки Supabase/Google и отдельные Android-файлы.

## 4. ИИ распознавания кота
Pipeline:
1. Загрузить и сжать изображение; не записывать base64 в БД.
2. Проверить, что изображение действительно содержит кошку. Если уверенность ниже порога — попросить другое фото и не начислять XP/не публиковать метку.
3. Вернуть структурированный JSON: `cat_detected`, confidence, кандидаты породы с вероятностями, окрас, рисунок шерсти, цвет глаз, видимые особенности мордочки/ушей/хвоста, поза и видимые аксессуары.
4. Настроение маркировать только как осторожную оценку видимых сигналов («похоже на расслабленного/настороженного»), показывать confidence и предупреждать, что по фото нельзя надёжно знать эмоциональное состояние животного.
5. Фоновое удаление делать отдельным шагом и хранить исходное фото отдельно от PNG cutout.
6. Сохранять версию модели и исходный структурированный результат для повторной оценки и отладки.
7. Не определять личность владельца или уникальную личность животного по морде. Порода по фото — предположение, особенно для беспородных кошек; показывать несколько кандидатов, а не категоричный диагноз.

## 5. Что остаётся неподключённым
- Edge Function source и secrets не доступны в репозитории, поэтому общие метки пока не могут записываться/читаться до добавления server actions.
- Миграцию SQL нужно применить в Supabase SQL Editor.
- Google/Apple OAuth надо включить в Dashboard и настроить redirect URLs.
- Перед публикацией проверить `npm run build`, Vercel deployment и поведение на Android.
