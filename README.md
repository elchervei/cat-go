# Cat Go — стартовый проект

## Что уже есть
- Мобильный интерфейс на React + Vite
- Фото через камеру Android или выбор из галереи
- Черновик карточки, XP и игровая редкость
- Характеристики (пока игровые случайные значения, не AI-анализ)
- Коллекция и сохранение данных в localStorage браузера
- Экспорт JSON-резервной копии
- Задания и профиль

## Запуск
Требуется Node.js 20+:
```bash
npm install
npm run dev
```
Открой URL, который выдаст Vite. Для доступа к камере браузер обычно должен быть на HTTPS или localhost.

## Честные ограничения текущей версии
- Фото в этой версии хранятся в браузере устройства. Очистка данных браузера может их удалить.
- Автоматическое удаление фона ещё не подключено.
- Редкость и характеристики назначаются игровым алгоритмом случайно, а не распознаются по фото.
- Это стартовый проект; Telegram Mini App и Supabase ещё не подключены.
